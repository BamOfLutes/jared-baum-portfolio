Authenticate

You must have a preexisting account (username and password) to access Oracle Health Clinical Data Exchange and permission to use the REST API. To request access to the REST API, contact your Oracle Health Clinical Data Exchange administrator.

Oracle Health Clinical Data Exchange utilizes the following types of authentication to obtain authorization tokens to use the REST API:

  • Signature: For proprietary Oracle Health Clinical Data Exchange endpoints. For more information on how to set up a signature in Oracle Cloud Infrastructure, see Authenticate with an Oracle Cloud Infrastructure signature.
  • Bearer token: For FHIR-compliant endpoints. These APIs use the FHIR R4 specification. For more information on how to gain an OAuth2 access token, see Authenticate with a bearer access token.
