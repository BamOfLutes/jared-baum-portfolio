Authenticate with an Oracle Cloud Infrastructure signature

This topic describes how to set up an API key using an Oracle Cloud Infrastructure signature.

Oracle Health Clinical Data Exchange utilizes Oracle Cloud Infrastructure signatures for generating API keys, which consist of the following:

  • Tenancy OCID: The unique ID for the Oracle Cloud Infrastructure tenancy
  • User OCID: The unique ID for the user that belongs to the Oracle Cloud Infrastructure tenancy
  • API Key FingerPrint: The unique ID for the API key FingerPrint

For information on generating an API key for Oracle Health Clinical Data Exchange, see the Token-based Authentication for the CLI topic in the Oracle Cloud Infrastructure Documentation on Oracle Help Center.
